# graph — UnivViewer 互換ビューア開発用の同梱ランタイム解析

このリポジトリには、横河電機（YOKOGAWA）のレコーダ向けデータ閲覧ソフトウェア **UnivViewer** に関連する実行モジュール、依存ライブラリ、および取扱説明書が格納されています。

この README の目的は、**`UnivViewer.exe` の代替実行ファイルを開発する際に、各ファイルが担うと考えられる役割を整理すること**です。

> [!IMPORTANT]
> `UnivViewer.exe` 本体は 25MB を超えるため、このリポジトリには含まれていません。
> そのため、ここでの役割整理は、格納済みファイルのバイナリ情報・依存関係・同梱マニュアルから確認できる内容に基づきます。未格納の本体内部実装や独自データ形式の完全な仕様は確認できません。

---

## 対象システムの概要

同梱されているマニュアル `IM04L41B01-63JA（取説）.pdf` は、YOKOGAWA の **DAQSTANDARD Viewer** に関する日本語マニュアルです。対象は DX1000 / DX1000N / DX2000 系のペーパーレスレコーダであり、記録データを PC 上で閲覧・解析・出力する用途のソフトウェアと判断できます。

`DLGADEngine.exe` 内の埋め込み依存情報からは、次の構成を確認できます。

- `DLGADEngine` バージョン: `1.01.01`
- `DLGADModule` バージョン: `1.0.0`
- `DLGADResource` バージョン: `1.0.0`
- `MathNet.Numerics` バージョン: `4.12.0`
- 対象ランタイム: `.NET Core 3.1 / win-x64`

## 確認できた依存関係

`DLGADEngine.exe` に含まれる依存情報から読み取れる関係は次のとおりです。

```text
DLGADEngine.exe
├─ DLGADModule.dll
│  ├─ DLGADResource.dll
│  └─ MathNet.Numerics.dll (4.12.0)
├─ DLGADModuleWrapper.dll
│  ├─ Ijwhost.dll
│  └─ DLGADModuleWrapper.runtimeconfig.json
└─ UnivViewer.lang
```

概念的には、以下の層に分けて考えると分かりやすくなります。

```text
[新しい Viewer GUI]
    ├─ ファイル選択、表示、ズーム、チャンネル選択、エクスポート
    ├─ グラフ描画、表形式表示、検索、印刷
    │
[データモデル / 解析層]
    ├─ 記録データ、チャンネル、単位、時刻、イベント、メタデータ
    ├─ 統計値、補間、フィルタ、範囲選択
    │
[データ読込層]
    ├─ 対象ファイル形式の識別
    ├─ バイナリ / テキストデータのデコード
    └─ エラー処理・整合性検証
```

既存ファイルでは、主に下位 2 層を `DLGAD*` コンポーネントが、上位の GUI を `UnivViewer.exe` が担っていた可能性があります。

## UnivViewer 代替アプリで目指す機能

マニュアルとバイナリ内の文字列から、少なくとも次の機能群が存在する、または想定されることが読み取れます。

### 最小実装（MVP）

1. 記録データファイルを選択して開く
2. チャンネル一覧を表示する
3. 時系列グラフを描画する
4. 時間範囲をズーム・パンする
5. 指定範囲の値を表形式で表示する
6. CSV 形式でエクスポートする
7. ファイル読込エラーを分かりやすく表示する

### 追加候補

- 最大値・最小値・平均値などの統計表示
- グラフの画像出力・印刷
- 複数チャンネルの重ね描きと軸設定
- カーソル位置の時刻・値表示
- イベント・アラーム情報の表示
- 多言語 UI
- 最近開いたファイル

## 新規実装の推奨方針

### 1. 既存の DLL 依存を最小化する

`DLGADModuleWrapper.dll` は .NET Core 3.1 と C++/CLI の混合構成に見えるため、新アプリケーションの中核として使うと、ランタイム・CPU アーキテクチャ・配布の制約を引き継ぐ可能性があります。

可能であれば、次の優先順位を推奨します。

1. **対象データ形式の正式仕様・公式 SDK がある場合はそれを利用する**
2. 公式に提供される変換機能・CLI・エクスポート機能がある場合は、その出力（CSV など）を新 Viewer で扱う
3. 互換性が必要なファイル形式のみを、独自のリーダーとして段階的に実装する
4. 既存 DLL の直接利用は、ライセンス、サポート範囲、技術的互換性を確認できた場合だけ検討する

### 2. 新規実装の技術スタック案

- Runtime: **.NET 8 LTS 以降**
- GUI: WPF / WinUI 3 / Avalonia のいずれか
- グラフ描画: ScottPlot、OxyPlot、LiveCharts などを比較検討
- データモデル: `DateTimeOffset` + `double` を基本とし、チャンネル単位・名称・測定レンジ・欠損値を保持
- 出力: CSV を最初に実装し、必要に応じて Excel / PNG / PDF を追加

### 3. 先に確認したいこと

- 対象にする拡張子・データファイルの実サンプル
- 1 ファイルの最大サイズ、チャンネル数、サンプリング周期
- 必要な出力形式（CSV、Excel、画像、PDF）
- DX1000 / DX1000N / DX2000 のどの記録形式をサポートするか
- 既存 UnivViewer と完全互換にする必要があるか、閲覧・CSV 出力に絞るか

## ローカル検証メモ

### `UnivViewer.lang` の展開

このファイルは ZIP 形式として認識されるため、Windows では拡張子を `.zip` に変更するか、7-Zip 等で開ける可能性があります。

```powershell
Copy-Item .\UnivViewer.lang .\UnivViewer.zip
Expand-Archive .\UnivViewer.zip -DestinationPath .\UnivViewer-lang
```

展開後に `UnivViewer.txt` が取得できれば、画面文言・メニュー項目・機能名の把握に利用できます。

> 元ファイルは上書きしないでください。
